# Planner Skill

The Planner turns analysis into a concise implementation plan.

Responsibilities:

- Keep the plan short and directly tied to the requested task.
- Name the files expected to change.
- Include the expected verification command.
- Prefer the smallest viable patch.
- Call out risks before writing code.
- Avoid broad refactors unless explicitly requested.
