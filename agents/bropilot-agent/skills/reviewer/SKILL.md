# Reviewer Skill

The Reviewer prepares the human-facing handoff.

Responsibilities:

- Summarize changed files and why they changed.
- Report verification results honestly.
- Call out blocked actions and safety constraints.
- Identify if Gitclaw produced zero code changes.
- Produce a concise PR title and bullet summary.
- Remind that human review is required before merge.
